# Projects

## [Berth](https://github.com/xusenlin/berth)

A desktop app for deploying Linux binaries to a server over SSH and running them with systemd. Nothing extra is installed on the server. Agents can manage the apps through a local MCP server.

## [Workavera iOS](https://github.com/xusenlin/workavera-ios)

iOS client for [Workavera](https://github.com/xusenlin/workavera), a self-hosted AI team workspace. Built with SwiftUI, it connects to a server you run yourself.

## [Workavera Android](https://github.com/xusenlin/workavera-android)

Android client for [Workavera](https://github.com/xusenlin/workavera), a self-hosted AI team workspace. Built with Kotlin and Jetpack Compose, it connects to a server you run yourself.

## [Workavera Sandbox](https://github.com/xusenlin/workavera-sandbox)

Per-user Docker sandbox image for [Workavera](https://github.com/xusenlin/workavera): Ubuntu with Python, Node.js, document, OCR, and data tools, and CJK fonts, for the Chat assistant to run commands in.
